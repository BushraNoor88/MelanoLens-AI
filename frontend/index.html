MelanoLens AI — Skin Lesion Boundary Enhancement and Detection Using Computer Vision. Skin lesion borders can be low-contrast, blurry or noisy, so ordinary edge detection often gives broken contours. The Edge Booster strengthens meaningful gradients before detection, and this app lets you compare the result with conventional detection on the same image. It is an educational tool, not a diagnostic one.

Algorithms

Edge detectors

Canny detector

Gaussian smoothing, gradient, non-maximum suppression and two-threshold hysteresis give thin, connected edges.

Sobel detector

3×3 derivative kernels give Gx and Gy; magnitude sqrt(Gx² + Gy²) is thresholded.

Prewitt detector

Like Sobel but with equal weights in the kernel rows, applied with explicit convolution.

Laplacian detector

Second derivative; edges are where intensity curvature is strong. Sensitive to noise.

Laplacian of Gaussian optional

Gaussian smoothing first, then the Laplacian, which tames noise at the cost of fine detail.

Edge Booster methods

Sobel gradient

I' = normalize(I + α·G)

Adds the normalised gradient back to the image. Large α amplifies noise.

Laplacian sharpening

I' = I − s·∇²I

Unsharp-style sharpening using the Laplacian with a negative centre.

Morphological gradient

dilate(I) − erode(I)

Edge thickness from dilation minus erosion; kernel size sets the scale.

Multi-scale experimental

Sobel responses at several blur scales, each normalised, then combined with weights.

Research question

Does edge enhancement improve skin lesion boundary detection compared with conventional edge detection? Upload an image (optionally with a reference mask) and use the Evaluation page to investigate it with real computed numbers. Enhancement can make edges look stronger without making the segmentation more accurate; the app reports both outcomes as they are.
